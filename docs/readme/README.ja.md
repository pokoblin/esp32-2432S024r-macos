# Sysmon：ESP32-2432S024R で作る Mac のステータス画面

[English](../../README.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | **日本語** | [한국어](README.ko.md) | [Español](README.es.md) | [Français](README.fr.md) | [Deutsch](README.de.md) | [Português (Brasil)](README.pt-BR.md) | [Русский](README.ru.md)

ESP32-2432S024R（2.4 インチ ST7789 搭載ボード、通称「Cheap Yellow Display」）を、モニターの横に置く小さなステータス画面にします。CPU、メモリ負荷、ネットワーク速度、Claude と ChatGPT のサブスクリプションの残り枠が一目でわかり、休憩・立ち上がり・水分補給を促すポモドーロタイマーも付いています。

メニューバーアプリの **Sysmon** が 2 秒ごとに Mac の状態を取得し、USB シリアルでボードに送ります。リングやグラフはボードが描画します。Wi-Fi は不要で、Mac のポートを開くこともありません。

![モニターの横に置いた Sysmon の画面](../images/sysmon-preview.jpg)

<sub>イラストはファームウェアの実際のレイアウトと配色に基づいて描いたもので、数値はダミーです。</sub>

> **言語について：** Mac アプリは 10 言語に対応しています。ボード自体は現在、中国語のテキストのみを表示します。この README の画像は、同じ画面を英語で表示したものです。

## 画面

縦向き 240×320、背景は暗色です。画面は 4 種類で、システム、ポモドーロ、Claude 使用量、ChatGPT 使用量です。リマインダーバナーはどの画面にも重ねて表示されます。

![4 つの画面](../images/screens.jpg)

### システム

- **上部：** CPU とメモリ負荷のリング。CPU は 50% で黄色、80% で赤になります。メモリのリングは macOS のメモリ負荷レベル（正常 / 警告 / 重大）に従い、アクティビティモニタと同じ見え方です。
- **下部：** 現在のダウンロード速度とアップロード速度、および直近 5 分間の 2 色グラフ。グラフは 5 分間のピーク値に合わせて拡縮します。

### ポモドーロ

- 大きなリングで現在のセッションの残りを示し、残り時間、フェーズ、終了時刻を表示します。集中はトマトレッド、短い休憩は緑、長い休憩は青で、一時停止中と未開始のときはグレーです。
- 下には、今のラウンドの進行を示すドット（既定では 1 ラウンド 4 回の集中）と、たとえば「2 回目 · 長い休憩まであと 2 回」、そして今日の集計、たとえば「今日 5 回 · 2 時間 05 分」が出ます。
- 既定値：集中 25 分、短い休憩 5 分、集中 4 回ごとに長い休憩 15 分。すべて変更でき、変更は次のセッションから反映されます。
- 手動で開始する必要があるのは集中だけです。集中が終わるとそのまま休憩に入り、休憩が終わるとあなたの操作を待ちます。
- 開始・一時停止・再開は、グローバルショートカット 1 つ、またはメニューから行います。メニューには「スキップ」と「ラウンドをリセット」もあります。集中中にスキップするとその集中は破棄され、集計には入りません。
- タイマーは実時間で動くので、席を外していても、画面がロックされていても、Mac がスリープしていても進み続けます。今日の集計は午前 0 時にリセットされ、再起動しても保持されます。
- 集中中は、ほかの画面の最上部に細い 3 px のトマトレッドの進捗ラインが表示されます（一時停止中はグレー）。

### Claude と ChatGPT の使用量

- 大きなリングで 5 時間枠とリセットまでの時間を示し、週間枠はバーで表示します（「今週 · 木曜 14:00 にリセット」）。Claude の画面では、API が返す場合にモデル別の週間枠も表示します。
- 色のしきい値は CPU と同じです。フッターにはプラン（Max、Plus など）とデータの鮮度が表示されます。
- 古いデータには必ず印が付きます。ログインの期限が切れていると「期限切れ」、リクエストが失敗すると「読み取り失敗」、枠がすでにリセットされている場合は「--」と表示されます。

### リマインダーバナー

![4 種類のリマインダーバナー](../images/banners.jpg)

どの画面を表示していても、バナーが画面全体を覆い、ボード背面の RGB ライトも同じ色でゆっくり点滅します（ライトはオフにできます）。ボードをタップするか、画面切り替えのショートカットを押すと閉じます。

| バナー | 表示されるタイミング | 色 | 自動で消えるか |
|---|---|---|---|
| 集中完了 | 集中が終わり、休憩が始まるとき。休憩のカウントダウンと、集中中に保留されたリマインダーも表示 | 緑 | 休憩が終わると消える |
| 休憩終了 | 休憩が終わるとき | 赤 | 次の集中を始めると消える |
| 立ち上がりましょう | 実際にコンピュータを使って 50 分 | オレンジ | 5 分離れると消える |
| 水分補給の時間です | コンピュータを使って 60 分 | 青 | 消えない（タップで閉じる） |

- 「コンピュータを使っている」とは、キーボードまたはマウスの操作があることを指します。アイドル時間や、画面のロック・スリープ中は離席として積算されます。5 分離れると立ち上がりタイマーが、30 分離れると水分補給タイマーがリセットされます。
- 集中中（一時停止中を含む）はバナーを表示しません。保留されたリマインダーは「集中完了」バナーにまとめて表示されます。
- バナーは一度に 1 つだけ表示され、順序は表のとおりです。

### 画面の切り替えと消灯

- 順序：システム → ポモドーロ → Claude → ChatGPT。ボードのどこかをタップするか、グローバルショートカットを押します。バナーの表示中は、同じ操作でバナーが閉じ、画面は切り替わりません。
- 設定でオフにした画面はスキップされます。右上のページドットで現在位置がわかります。
- ディスプレイのスリープ、画面ロック、ユーザ切り替え、Mac のスリープが起きると、画面とライトはすぐに消え、復帰すると自動で戻ります。Sysmon を終了するかケーブルを抜くと、約 10 秒後に画面が消えます。

## メニューバーアプリ

- アイコンは ESP32 モジュールで、ボードが接続されていないときはスラッシュが付きます。
- メニューには、接続状態、現在使えるポモドーロの操作、設定、Sysmon について、終了が並びます。
- 設定は 4 つのタブに分かれています。
  - **一般：** 画面の切り替えのショートカット、RGB ライト、アプリの言語（システムに合わせる、または 10 言語から選択）、ログイン時に起動。
  - **ポモドーロ：** ポモドーロ画面、開始 / 一時停止のショートカット、各時間、1 ラウンドあたりの回数。
  - **リマインダー：** 立ち上がりリマインダーと水分補給リマインダー、およびその間隔。
  - **使用量：** Claude と ChatGPT の使用量の画面とその状態、データの取得元。
- グローバルショートカットは Carbon ホットキーを使うので、アクセシビリティの権限は不要です。席にいるかどうかの判定にはシステムのアイドル時間を読み取りますが、これにも権限は不要です。
- WCH（CH340）の USB ベンダー ID でボードを見つけ、抜き差ししても再接続します。ポートを開閉してもボードがリセットされることはありません。
- CPU 使用率は 0% に近いままです。

### 使用量データの取得元

Sysmon は、Mac にすでにあるログイン情報を読み取り専用で借ります。

- **Claude：** ログインキーチェーン内の Claude Code の認証情報（項目 `Claude Code-credentials`。`/usr/bin/security` 経由で読み取るため、許可のプロンプトは出ません）を、Anthropic の使用量エンドポイントに送ります。
- **ChatGPT：** Codex の `~/.codex/auth.json` を、ChatGPT の使用量エンドポイントに送ります。

Sysmon はこれらのログインを更新せず、キーチェーンや `auth.json` に書き込むこともないので、ログアウトさせてしまうことはありません。ただし、Claude Code や Codex をしばらく使わないとログインの期限が切れ、画面は最後の数値のまま「期限切れ」と表示されます。復旧するには、ターミナルで `claude` を一度実行するか、Codex を一度開いてください。2 分以内に新しい数値が表示されます。使用量は 2 分ごとに取得し、画面が消えている間は取得しません。

どちらのエンドポイントも非公開で、変更される可能性があります。片方を解析できなかった場合は、その画面だけが「読み取り失敗」と表示されます。

## 必要なもの

| 項目 | 要件 |
|---|---|
| ボード | ESP32-2432S024R（ESP32-D0WD-V3、4 MB フラッシュ、ST7789 240×320、CH340 シリアル） |
| Mac | macOS 14 以降 |

## クイックスタート

```bash
git clone git@github.com:pokoblin/esp32-2432S024r-macos.git
cd esp32-2432S024r-macos
```

### 1. ファームウェアを書き込む

```bash
cd sysmon/firmware
pio run -e esp32dev -t upload
```

`platformio.ini` では `/dev/cu.usbserial-114110` を使っています。お使いのポートに書き換えてください（`ls /dev/cu.usbserial-*`）。書き込み前に Sysmon を終了しておかないと、ポートが使用中になります。

> このボードは USB ハブ経由だと 921600 と 460800 では書き込みに失敗するため、`upload_speed` は 115200 に固定しています。

### 2. メニューバーアプリをインストールする

```bash
cd sysmon/macos
bash scripts/bundle.sh
open ~/Applications/Sysmon.app
```

`bundle.sh` はリリースビルドを作成し、`Sysmon.app` を生成して ad hoc 署名を付け、`~/Applications` にインストールします。必要に応じて、設定で「ログイン時に起動」をオンにしてください。

## 開発

テストの実行：

```bash
cd sysmon/firmware && pio test -e native
cd sysmon/macos && swift test
```

Sysmon なしでボードを動かす（pyserial が必要です。PlatformIO 付属の Python には入っています）：

```bash
python sysmon/tools/fake_feed.py /dev/cu.usbserial-114110                    # --page で sys / pomo / cl / gpt を指定
python sysmon/tools/fake_feed.py /dev/cu.usbserial-114110 --cycle            # 画面を自動で切り替える
python sysmon/tools/fake_feed.py /dev/cu.usbserial-114110 --page pomo --phase paused
python sysmon/tools/fake_feed.py /dev/cu.usbserial-114110 --banner done      # done / brk / sit / water
python sysmon/tools/fake_feed.py /dev/cu.usbserial-114110 --off
```

バナーのタイトルには、必要な文字だけを含む小さなフォントを使っています（ファームウェアはすでにフラッシュの 90% 以上を使っています）。`lib/sysmon_core/banner_titles.h` のタイトルを変更したら、フォントを再生成してください。フォントは源ノ角ゴシック CN Bold（SIL Open Font License 1.1）で、ローカルにインストールしておく必要があります。

```bash
swift sysmon/tools/make_banner_font.swift ~/Library/Fonts/SourceHanSansCN-Bold.otf 24
```

README の画像は `docs/images/make_preview.py` と `docs/images/make_screens.py` で生成します。コマンドは各スクリプトの冒頭に書かれています。

### シリアルプロトコル

115200 8N1、プレーンテキスト、1 行に 1 レコード：

```
S cpu=37 mem=51 lvl=1 rx=13002342 tx=880640
OFF
```

| フィールド | 意味 |
|---|---|
| `cpu` | CPU 使用率、0–100 |
| `mem` | メモリ負荷の割合、0–100 |
| `lvl` | メモリ負荷レベル：1 正常、2 警告、4 重大 |
| `rx` / `tx` | ダウンロード / アップロード速度、バイト毎秒 |
| `OFF` | 次の `S` 行が来るまで画面を消す |

ファームウェアは未知の行やフィールドを無視します。ページ、使用量、ポモドーロ、バナーには `P`、`U`、`T`、`B` の各行を使い、ボードはタップされると `TAP` を送ります。詳しくは `usage_protocol.h`、`timer_protocol.h`、`Protocol.swift` のヘッダコメントを参照してください。

## ハードウェアメモ

- ディスプレイコントローラは ILI9341 ではなく **ST7789** です。`Panel_ILI9341` を使うと、画像が転置・ミラーされて表示されます。
- LovyanGFX の設定：`rgb_order=false`（true にすると赤と青が入れ替わります）、`invert=false`、回転 0。
- バックライトは GPIO27 で、アクティブハイです。ディスプレイの MISO は接続されていないため、ID は読み取れません。
- 背面の RGB LED はコモンアノードのアクティブローです：GPIO4 が赤、GPIO16 が青、GPIO17 が緑（青と緑は、多くの CYD 関連の資料に書かれているのとは逆です）。
- CH340 は DTR/RTS で EN と GPIO0 を駆動します。Sysmon はポートを開いた直後に両方をクリアし、`HUPCL` を無効にするので、ポートを開閉してもボードがリセットされることはありません。
